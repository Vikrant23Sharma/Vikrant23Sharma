## 👋 About Me

I'm a **Bachelor of Management Studies** graduate (Marketing) who fell for the numbers behind the market. I work at the point where **business questions meet data**: cleaning messy datasets, defining the right KPIs, and building dashboards that people actually use to make decisions.

- 📊 Build end-to-end analyses: **raw data → SQL → KPIs → interactive dashboards → insights**
- 🧹 Comfortable with data cleaning, statistical analysis, and exploratory analysis
- 🎯 Bring a marketing lens: customer behaviour, pricing, and market trends
- 🌱 Currently sharpening: advanced SQL and dashboard storytelling
- 🤝 Open to **Data Analyst / Business Analyst** roles and collaborations

## 📈 How I Approach a Problem

```text
1. Understand the business question   → what decision does this support?
2. Clean & model the data             → SQL / Excel
3. Define KPIs that matter            → measurable, comparable, actionable
4. Visualize                          → Power BI / Tableau dashboards
5. Tell the story                     → insights + recommendations
```
